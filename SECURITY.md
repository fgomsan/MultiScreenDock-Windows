# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.5.x   | :white_check_mark: |

## Privacy & Architecture Guarantees

- **Zero Telemetry & Zero Network Calls:** MultiScreenDock for Windows runs 100% locally on your PC and never transmits user data.
- **Standard Win32 Window Geometry Only:** Uses standard `EnumWindows` and `DwmGetWindowAttribute` window bounds without injecting hooks into other processes.

## Reporting a Vulnerability

Please report security issues via [GitHub Security Advisories](https://github.com/fgomsan/MultiScreenDock-Windows/security/advisories/new) or by opening an issue on GitHub.
